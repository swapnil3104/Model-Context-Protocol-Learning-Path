# Installing the MCP SDK

Before building an MCP Server, you need to install the official Model Context Protocol (MCP) SDK.

The SDK provides everything required to create MCP-compliant servers, including tools, resources, prompts, transports, and communication protocols.

---

In this section, you will learn how to:

- Create a new MCP project

- Run your first MCP application

# Official MCP SDKs

Currently, the official SDKs are available for:

- TypeScript / Node.js
- Python

These SDKs simplify the implementation of MCP servers by handling communication, protocol compliance, and server lifecycle management.

---

# Why Use the Official SDK?

The SDK provides:

- Built-in MCP protocol support
- Tool registration
- Resource management
- Prompt registration
- Transport handling
- Schema validation
- Error handling
- Faster development
