# Environment Setup

Before building your first MCP (Model Context Protocol) server, you need a proper development environment.

This section walks you through installing the essential tools required for MCP development.

---

## 📚 What You'll Learn

- Install Node.js
- Install Python
- Choose a code editor
- Install useful VS Code extensions
- Verify your installation
- Prepare your machine for MCP development

## Software You'll Need

- Node.js (LTS)
- npm
- Python 3.10+
- pip
- Visual Studio Code
- Git

---

## Verify Your Setup

### Node.js

```bash
node -v
```

### npm

```bash
npm -v
```

### Python

```bash
python --version
```

or

```bash
python3 --version
```

### pip

```bash
pip --version
```

### Git

```bash
git --version
```
