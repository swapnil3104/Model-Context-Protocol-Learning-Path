# Official Resources

> The **Model Context Protocol (MCP)** is an open standard with a growing ecosystem of official documentation, SDKs, reference implementations, and community projects. These resources help developers understand the protocol, build MCP clients and servers, and integrate AI applications with external tools securely and efficiently.

Whether you're a beginner learning the fundamentals or an experienced developer building production-ready AI systems, these official resources provide everything you need to get started with MCP.

---

# Why Use Official Resources?

Official documentation ensures that you:

- Learn the latest MCP specifications
- Follow recommended best practices
- Build compatible MCP Clients and Servers
- Stay updated with protocol changes
- Explore reference implementations
- Access official SDKs and examples

Instead of relying on outdated tutorials, always refer to the official documentation whenever possible.

# Best Practices

While learning MCP:

- Start with the official documentation.
- Read the protocol specification.
- Build small projects before large ones.
- Explore official reference servers.
- Follow SDK examples.
- Learn JSON-RPC basics.
- Practice creating custom tools.
- Contribute to open-source MCP projects.
